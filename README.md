# 🧠 Mental Health Risk Intelligence System

## Overview

Mental Health Risk Intelligence System is an AI-powered early warning
application built using Streamlit. The system analyzes user-entered text
and predicts emotional risk levels by combining sentiment analysis,
emotion detection, critical phrase detection, explainable AI, and risk
trend visualization.

The application is designed as a demonstration system for detecting
possible indicators of stress, anxiety, depression, and emotional
distress from textual data.

## Features

-   Text-based mental health risk prediction
-   Risk score calculation (0--100)
-   Risk categorization:
    -   Low Risk
    -   Moderate Risk
    -   High Risk
-   Sentiment analysis
-   Emotion distribution visualization
-   Critical phrase detection
-   Explainable AI using SHAP
-   Historical analysis storage
-   Risk trend graph visualization
-   Interactive dashboard using Streamlit

## Installation

### Clone repository

``` bash
git clone <repository-url>
cd MentalHealthAI
```

### Install dependencies

``` bash
pip install -r requirements.txt
```

### Run application

``` bash
streamlit run app.py
```

## Example Inputs

### Example 1 (Low Risk)

Input:

``` text
I had a productive day today and I feel happy and relaxed.
```

Expected Output:

``` text
Risk Level: Low
Risk Score: ~10–25%
```

------------------------------------------------------------------------

### Example 2 (Moderate Risk)

Input:

``` text
I feel stressed because of my exams and I cannot focus properly.
```

Expected Output:

``` text
Risk Level: Moderate
Risk Score: ~40–65%
```

------------------------------------------------------------------------

### Example 3 (High Risk)

Input:

``` text
I am stressed about exams and my future.
I feel lonely and exhausted lately.
Sometimes I feel hopeless and scared.
```

Expected Output:

``` text
Risk Level: High
Risk Score: ~75–100%
Critical Alert: Severe emotional distress detected
```
